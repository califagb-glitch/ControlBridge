# DeepCore ⛏️

Incremental de mineração para **Android e Windows**.

## Protótipo 0.1
- Mineração manual por toque/clique.
- Profundidade crescente.
- Venda de minério por créditos.
- Upgrade de picareta.
- Furadeira automática.
- Interface única adaptável para desktop e mobile.

## Próximas etapas
1. Sistema real de recursos e raridades.
2. Minério por camadas e profundidade.
3. Inventário e armazenamento.
4. Máquinas e automação.
5. Cavernas descobríveis.
6. Eventos e achados raros.
7. Save offline e progresso enquanto fechado.
8. Prestige/renascimento da operação.
9. Arte, animações, partículas e áudio.
10. Exportações Android e Windows.

> O projeto está começando pequeno de propósito: cada sistema será testado antes de aumentar a complexidade.
