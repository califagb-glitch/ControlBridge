# DeepCore

Incremental mining game for Android and Windows, built with Godot 4.

## First milestone
- Mine manually
- Sell ore
- Upgrade pickaxe
- Buy an automated drill
- Depth progression
- Mouse/touch + keyboard controls

## Controls
- **Space:** mine
- **S:** sell
- **1:** upgrade pickaxe
- **2:** upgrade drill

The project is intentionally small at first so every system can be tested before expanding the game.
